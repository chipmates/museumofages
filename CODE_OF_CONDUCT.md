# Code of Conduct

## Our commitment

Museum of Ages is a digital museum by ChipMates gemeinnützige GmbH, a German nonprofit. We rebuild what was. You walk through it. This code of conduct is about how we work together on it.

We want taking part in this project to be respectful, constructive and welcoming, whatever a person's age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

---

## Expected behavior

- **Be respectful.** Treat others the way you want to be treated. Disagreement is fine, disrespect is not.
- **Be constructive.** Offer helpful feedback. Focus on the work, not the person.
- **Be welcoming.** Help newcomers get started. Answer questions patiently. Remember that everyone was new once.
- **Be professional.** Keep discussions focused on the project. Assume good intent.
- **Be inclusive.** Use language that is welcoming to a broad audience. Respect differing viewpoints and experiences.

---

## Unacceptable behavior

- Personal attacks, insults, or deliberately inflammatory comments
- Unwelcome or inappropriate contact of any kind
- Publishing others' private information without consent
- Sustained disruption of discussions or contributions
- Any conduct that would be considered inappropriate in a professional setting

---

## Scope

This Code of Conduct applies to all project spaces: GitHub issues, pull requests, code reviews, mail to the project, and any other channel of Museum of Ages. It also applies when someone represents the project in public spaces.

---

## Enforcement

Report unacceptable behavior to ChipMates gemeinnützige GmbH, which runs the museum, at **contact@museumofages.org**. We answer every report within two weeks, and we review it fairly, hearing everyone involved.

If your report concerns the person who reads that address, report it to GitHub instead, with the report option on the comment, issue or profile.

ChipMates decides on the response, which may include:

1. **Correction.** A private conversation about the impact of the behavior.
2. **Warning.** A formal notice with expectations for future conduct.
3. **Temporary restriction.** A temporary ban from project spaces.
4. **Permanent restriction.** A permanent ban from project spaces.

All reports will be handled with discretion and respect for the privacy of everyone involved.
